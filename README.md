# MGY — MindGuruYoga
### Clarity, without noise.

MindGuruYoga (MGY) is a premium, ultra-minimal platform for mindfulness, psychology, and productivity. It is designed to help modern intellectuals master their internal state and achieve deep work through a structured curriculum for consciousness.

![MGY Preview](https://github.com/user-attachments/assets/0aa67016-6eaf-458a-adb2-6e31a0763ed6)

## ✨ Key Features

- **🧠 Psychology:** Evidence-based cognitive framing techniques to restructure your mental approach.
- **⚡ Flow State:** Integrated audio engines designed to induce and maintain deep focus.
- **🌙 Restoration:** Professional NSDR (Non-Sleep Deep Rest) and sleep protocols for rapid recovery.
- **🎯 Attention:** Specialized drills to improve and sustain concentration during demanding tasks.
- **📊 Analytics:** Proprietary clarity scoring system to track your mental evolution over time.
- **🛡️ Privacy:** Complete data sovereignty. Your mental data is encrypted and stays under your control.
- **🌌 Dynamic Interface:** A responsive "Constellation" background that morphs its geometry as you navigate through different modules.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** Vanilla CSS with modern Design Tokens (Glassmorphism, Harmonic Gradients)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Visualization:** HTML5 Canvas API for interactive constellation morphing.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/NishantRajiitkgp/MGY-Constillation-Theme.git
   cd MGY-Constillation-Theme
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## 📂 Project Structure

- `components/`: Modular React components (Hero, Features, ConstellationCanvas, etc.)
- `constants.ts`: Design system tokens and constellation geometry states.
- `types.ts`: TypeScript interfaces and type definitions.
- `index.tsx` & `App.tsx`: Application entry point and layout logic.
